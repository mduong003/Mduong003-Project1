# CSCI 5607 Project 1: Interactive 2D Geometry

This repository showcases my **CSCI 5607 Project 1**, which is intended to showcase a hands-on introduction to real-time graphics programming.  

## Project Overview

The goal of this project was to develop a simple application that demonstrates many of the basic features of the **OpenGL API**, while also supporting user interaction with the graphics on the screen.  

The features implemented:

- Translating only when the user drags on the square's interior (but not on the
edge or outside the square)
- Scaling the square when the user drags on the corners
- Rotating the square when the user drags on the edges
- Texture the square with an image loaded from a PPM file
- Significantly brighten the image on the square (without distorting the colors)
- Pressing ‘r’, resets the square’s position, scale, and orientation
- Adjust the image brightness using the 'up' and 'down' keys
